# Contributing to Swatcher

Contributions are welcome! Before submitting, please read this guide.

## Branching
- `main` — stable, production-ready
- `develop` — active development
- `feature/your-feature` — new features
- `fix/your-fix` — bug fixes

## Commit Messages
Use conventional commits:
- `feat: add dashboard variables`
- `fix: correct VictoriaMetrics query timeout`
- `chore: update dependencies`
- `docs: update README`

## Pull Requests
- Base all PRs on `develop`
- Describe what you changed and why
- Include test steps if applicable
